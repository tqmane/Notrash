## 有効にする

1. Vector / LSPosedで `com.nothing.camera` を対象にします。
2. Notrashの「カメラ → シャッター音」をONにします。
3. カメラを終了して開き直します。
4. 純正カメラの「その他の設定」からシャッター音を選びます。

Notrashのスイッチは**制限を解除するための設定**です。シャッター音そのもののON/OFFは、純正カメラで選びます。

## OFFに戻す

NotrashのスイッチをOFFにして、カメラを開き直してください。起動時に保存される設定があるため、画面を閉じるだけでは元の状態に戻らない場合があります。

## 設定が見つからないとき

- スコープに `com.nothing.camera` が含まれているか確認します。
- カメラを完全に終了してから開き直します。
- [確認済みのバージョン](/docs/compatibility)と比較します。

制限の仕組みとフック箇所は[カメラのWiki](/wiki/camera)にまとめています。
