Notrashは、Nothing OS向けの非公式な拡張モジュールです。Vector / LSPosed上で動作し、必要な機能をアプリから個別に切り替えられます。

## できること

| 機能 | 変わること |
| --- | --- |
| [カメラ](/docs/camera) | 隠れたシャッター音設定を表示し、マナーモード中も切り替え可能にする |
| [Essential Voice](/docs/essential-voice) | 機種制限を解除し、純正の設定入口とキーボードボタンを利用する |
| [表示設定](/docs/appearance) | ライト／ダークと、2つのコントラストを選ぶ |

拡張機能の初期状態はすべてOFFです。モジュールを読み込んだだけで、カメラやVoiceが一括で有効になることはありません。
