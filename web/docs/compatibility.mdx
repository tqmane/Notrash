## 確認した動作

- シャッター音設定の表示・非表示と、マナーモード中の操作。
- 純正Essential一覧のVoice入口の表示・非表示。
- 起動済みRecorderへの設定反映。
- Gboard下部の黄色いVoiceボタン。OFFで消え、ONで再表示。
- 4配色と表示設定の保存。文字サイズ1.3での表示。
- API 102のホットリロード。OSプロセスを再起動せず更新。

## OS側に必要な実装

Voiceには、Nothing OSの `NtEssentialVoiceImpl` が必要です。APKのインストールや機種判定の変更だけで、この実装がないOSにVoice一式を追加するものではありません。

Notrashアプリ自体の最小Android APIは26ですが、Voice本体のAPKやフレームワークにもそれぞれ要件があります。アプリがインストールできることと、すべての機能が動作することは別です。
