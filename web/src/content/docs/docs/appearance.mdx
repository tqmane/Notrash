## テーマ

ホームの「表示 → テーマ」から選びます。

| 設定 | 動作 |
| --- | --- |
| システム | 端末のライト／ダーク設定に従う。初期値 |
| ライト | Notrashをライト表示に固定する |
| ダーク | Notrashをダーク表示に固定する |

## ハイコントラスト

初期状態はONです。テーマとは別に切り替えられます。

| テーマ | ON | OFF |
| --- | --- | --- |
| ダーク | 黒を基調に赤のアクセント | 黒・白・グレー中心 |
| ライト | 白を基調に赤のアクセント | 白・グレー中心 |

トグルはモノクロです。ホームのタイトルはNType、セクションとアプリ情報の見出しにはドット書体を使用します。

選択は保存され、アプリを開き直しても維持されます。変更するのはNotrashの表示だけで、他アプリや端末全体の配色は変えません。

## アプリ情報

ホーム右上の情報ボタンから開きます。表示しているバージョン、接続フレームワーク、Android、機種は実際の値です。
