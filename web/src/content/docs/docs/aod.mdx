## 有効にする

1. Vector / LSPosedで `com.android.settings` をNotrashの対象にします。
2. Notrashの「ディスプレイ → 常時AOD」をONにします。
3. Notrashの「対象アプリを終了」を実行するか、設定アプリを完全に終了して開き直します。
4. 本体設定の「ロック画面 → 常に表示」を開きます。
5. 「表示するタイミング」から「常に表示」を選びます。

Notrashのスイッチは、隠されている**純正の選択肢を表示する設定**です。スイッチをONにしただけではAODの現在モードを変更しません。

## OFFに戻す

「タップして表示」または「スケジュール」へ戻したい場合は、先に本体設定で選び直してください。その後、Notrashの常時AODをOFFにして設定アプリを開き直すと、「常に表示」が再び隠れます。

NotrashをOFFにしても、選択済みのAODモードを勝手に変更しません。

## 項目が追加されないとき

- スコープに `com.android.settings` が含まれているか確認します。
- Notrashの常時AODがONか確認します。
- 設定アプリを履歴から閉じるだけでなく、完全に終了して開き直します。
- [確認済みの環境](/docs/compatibility)と比較します。
