## 確認した動作

- シャッター音設定の表示・非表示と、マナーモード中の操作。
- 本体設定の表示タイミングに純正の「常に表示」が追加され、選択後に画面OFFでDOZEへ移行すること。
- Notrash 1.0.3の上書きインストールと、Settingsを含むVectorスコープ。

Camera 16.0.01.26.00、Recorder 16.0.60、Space 2.1.7、Android 16での過去の検証結果は各Wikiに残しています。上の現行Recorder / SpaceでVoice一式を再検証した結果ではありません。

## OS側に必要な実装

Voiceには、Nothing OSの `NtEssentialVoiceImpl` が必要です。APKのインストールや機種判定の変更だけで、この実装がないOSにVoice一式を追加するものではありません。

Notrashアプリ自体の最小Android APIは26ですが、Voice本体のAPKやフレームワークにもそれぞれ要件があります。アプリがインストールできることと、すべての機能が動作することは別です。

## 未確認の範囲

他機種・他OTAの全組み合わせ、現行Recorder / SpaceでのVoice一式、全言語の認識と翻訳精度、すべての入力欄への挿入、全撮影モードでの撮影音は網羅していません。
